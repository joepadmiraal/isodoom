# Tasks

Each task is sized for one fresh Claude Code session. Start a session with: *"Do task T1.2 from TASKS.md."*

Every milestone is broken down into tasks (M3–M10 on 2026-10-06). The later milestones' tasks are coarser: when a milestone is reached, a session first refines its tasks with what the earlier ones taught (that is a task in itself), splitting any task too big for one session. Milestone definitions are in SPEC §11.

Legend: `[ ]` todo, `[x]` done.
